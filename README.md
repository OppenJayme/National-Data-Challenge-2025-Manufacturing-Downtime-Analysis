# Emerson x DAPH National Data Challenge 2025

## Overview
End-to-end data analytics project completed for the Emerson x DAPH National Data Challenge 2025.

The objective was to transform raw datasets into actionable business insights through structured data cleaning, exploratory analysis, and dashboard development.

---

## Tools Used
- Microsoft Excel (data inspection and cleaning)
- SQL (data transformation and aggregation)
- Power BI (data modeling and dashboard visualization)

---

## Project Workflow

### 1. Data Cleaning
- Removed duplicate records
- Handled missing and null values
- Standardized formats (dates, numeric fields, categories)
- Created calculated columns and derived metrics

### 2. Data Analysis
- Identified key performance indicators (KPIs)
- Analyzed trends and distributions
- Compared performance across segments
- Extracted business-relevant insights

### 3. Dashboard Development
- Built an interactive executive dashboard
- Designed KPI summary cards
- Implemented trend visualizations
- Added filtering and drill-down capabilities
- Structured layout for clear decision support

---

## Key Outcomes
- Converted raw data into structured insights
- Applied end-to-end analytics workflow
- Strengthened SQL, data modeling, and visualization skills
- Delivered insight-driven reporting aligned with business decisions

---

## Analytics Lifecycle
Raw Data → Cleaning → Transformation → Analysis → Visualization → Insight
